# Графики презентаций

`labs_2_3/` и `labs_4_5/` содержат изображения, извлечённые без изменения
пикселей из исходных PDF-презентаций при подготовке материалов 23 сентября 2026 года.
Они фиксируют тот набор иллюстраций, с которым были собраны презентации.

Пересборка оформления не требует запуска лабораторных. Изображения в `outputs/`
могут относиться к более поздним экспериментам, поэтому здесь они не подставляются
автоматически. Для обновления результатов нужно согласованно обновить графики,
таблицы и выводы в исходниках презентации.
